# Targets
-iL@ -i@|Read targets from the named list; a dash means standard input.
-iR@|Choose this many random IPv4 targets; zero requests an unbounded run.
--exclude@|Omit these comma-separated targets before discovery.
--excludefile@|Omit the addresses or networks listed in this file.
--unique|Visit each target address only once when specifications overlap.
--resolve-all|Scan every address returned for a target hostname.
-4|Use IPv4.
-6|Use IPv6; the installed build must support it.
# Discovery and DNS
-sn -sP|Discover responsive hosts without running a port scan.
-sL|List the targets without probing them; reverse DNS may still occur.
-Pn -P0 -PN -PD|Skip ordinary discovery and treat target addresses as up.
-PS?|Discover hosts with TCP SYN probes; an attached list selects ports.
-PA? -PT?|Discover hosts with TCP ACK probes; an attached list selects ports.
-PU?|Discover hosts with UDP probes on the selected ports.
-PY?|Discover hosts with SCTP INIT probes on the selected ports.
-PO?|Discover hosts with selected IP protocol probes.
-PE -PI -P|Send ICMP echo requests to discover hosts.
-PP|Use ICMP timestamp requests for discovery.
-PM|Use ICMP address-mask requests for discovery.
-PR|Legacy ARP discovery request; local Ethernet discovery is normally automatic.
-PB?|Legacy default IPv4 discovery mix; can specify ACK discovery ports.
--disable-arp-ping|Turn off implicit ARP or IPv6 neighbor discovery.
--discovery-ignore-rst|Ignore TCP reset replies when deciding whether a host is up.
-n|Skip reverse DNS lookups.
-R|Request reverse DNS even for targets that did not answer discovery.
--system-dns|Use the operating system resolver.
--dns-servers@|Use the specified DNS servers for supported lookups.
--traceroute|Trace the network path to responsive targets.
# Scan methods
-sS|Send TCP SYN probes; the port scan does not finish the handshake.
-sT|Ask the operating system to connect to each TCP port; an open port can accept a full connection.
-sU|Send UDP probes and classify ports using replies, errors, or silence.
-sA|Use TCP ACK probes to distinguish filtered from unfiltered paths; this does not identify open ports.
-sW|Inspect TCP window sizes in reset replies; useful only on some systems.
-sM|Use TCP FIN/ACK probes for a Maimon scan.
-sN|Send TCP probes with no flags set.
-sF|Send TCP FIN probes.
-sX|Send TCP probes with FIN, PSH, and URG flags set.
-sI@|Use the specified idle host for an IP-ID-based indirect scan.
-sY|Probe SCTP ports with INIT packets.
-sZ|Probe SCTP ports with COOKIE ECHO packets.
-sO|Test IP protocol numbers rather than transport ports.
-b@|Use an FTP relay for a bounce scan, if that server permits it.
--scanflags@|Set the TCP header flags used by a compatible scan.
# Ports and services
-p@|Select explicit ports, port ranges, service patterns, or protocol-qualified groups; a dash selects ports 1–65535.
-F|Use the fast port selection, normally the 100 most common per scanned protocol.
-r|Probe selected ports in ascending order.
--top-ports@|Select this many of the most frequent ports for each scanned protocol.
--port-ratio@|Select ports above a frequency threshold in the services database.
--exclude-ports@|Remove these ports from scanning and discovery probes.
-sV -sR|Probe services to identify what is listening and, where possible, its version.
--version-intensity@|Choose how extensively service probes are tried, from 0 through 9.
--version-light|Use a light service probe set (intensity 2).
--version-all|Try all service probes (intensity 9).
--version-trace|Show diagnostic details from service probing.
--allports|Include ports normally excluded from service detection.
--servicedb@|Read port names and frequency information from this services database.
--versiondb@|Use this service-probe database for version detection.
# Scripts and OS
-sC|Run the default NSE script set.
--script@|Select NSE scripts by name, category, path, or expression.
--script-args@|Pass the supplied names and values to NSE scripts.
--script-args-file@|Read NSE arguments from this file.
--script-trace|Show network communication generated by scripts.
--script-updatedb|Rebuild the local script index.
--script-help@|Display documentation for the selected scripts.
--script-timeout@|Stop an individual script instance after this time limit.
-O -O2|Request operating-system fingerprinting.
--osscan-limit|Attempt OS fingerprinting only on promising targets.
--osscan-guess --fuzzy|Allow less certain OS matches to be reported.
--max-os-tries@|Limit attempts to fingerprint a host’s operating system.
-A|Request OS and service detection, default scripts, and traceroute where available.
# Timing and performance
-T@ --timing@|Choose a timing template, from 0 (slowest) through 5 (most aggressive), or its name.
--min-hostgroup@|Set the preferred minimum number of hosts scanned as a group.
--max-hostgroup@|Limit the number of hosts in a scan group.
--min-parallelism@|Set a lower bound on outstanding probes.
--max-parallelism@ -M@|Limit the number of outstanding probes.
--initial-rtt-timeout@|Set the starting wait for a probe response.
--min-rtt-timeout@|Set the shortest adaptive response timeout.
--max-rtt-timeout@|Set the longest adaptive response timeout.
--max-retries@|Limit port-probe retransmissions; this many retries may follow the first attempt.
--host-timeout@|Stop work on an individual host after the specified time.
--scan-delay@|Wait at least this long between probes to the same host.
--max-scan-delay@|Limit the adaptive delay between probes to a host.
--min-rate@|Request a minimum overall discovery and port-probe sending rate, in packets per second.
--max-rate@|Limit the average discovery and port-probe sending rate across the scan, in packets per second.
--defeat-rst-ratelimit|Favor scan speed when TCP resets are rate-limited; closed and filtered ports may be harder to distinguish.
--defeat-icmp-ratelimit|Favor UDP scan speed when ICMP errors are rate-limited, at a cost to port-state detail.
--randomize-hosts -rH|Shuffle the order of target hosts within groups.
# Packet settings and routing
-f -ff|Fragment supported raw IP probes; repeating f increases the fragment size.
--mtu@|Specify a fragment size for supported raw probes.
-D@|Include decoy addresses alongside the real scanner in supported raw scans.
-S@|Use the supplied source IP address.
-e@|Use this network interface.
-g@ --source-port@|Set the source port for probes that support it.
--proxies@ --proxy@|Use a proxy chain for supported connection-based features; this does not route the whole scan through proxies.
--data@|Append the supplied hexadecimal payload to supported probes.
--data-string@|Append the supplied string as probe payload.
--data-length@|Append the given number of random payload bytes.
--ip-options@|Set IPv4 header options on applicable probes.
--ttl@|Set the outgoing packet time-to-live.
--spoof-mac@|Select a source MAC address, prefix, or vendor for supported Ethernet traffic.
--badsum|Use an intentionally invalid transport checksum on supported probes.
--adler32|Use the obsolete Adler-32 SCTP checksum.
--send-eth|Send applicable raw traffic as Ethernet frames.
--send-ip|Send applicable raw traffic as IP packets.
--route-dst@|Print the route Nmap would use to this destination.
# Output and diagnostics
-oN@ -o@|Write a normal text report to this file.
-oX@|Write an XML report to this file.
-oG@ -oM@ -m@|Write the legacy grepable report format.
-oS@|Write the novelty text report format.
-oA@|Request normal, XML, and grepable reports under one basename.
-v? --verbose -vv|Increase the amount of progress and result detail printed.
-d? --debug?|Enable debugging; an attached level selects the amount of detail.
--reason|Include the evidence behind reported states.
--open|Only display open or potentially open ports.
--packet-trace|Print information about sent and received packets.
--iflist|List the scanner’s interfaces and routes.
--append-output|Append results to existing output files.
--resume@|Resume an interrupted scan from a supported log file.
--noninteractive|Disable interactive keyboard shortcuts during a scan.
--stylesheet@|Associate XML output with the specified stylesheet.
--webxml|Associate XML output with Nmap’s hosted stylesheet.
--no-stylesheet|Do not associate XML output with a stylesheet.
--stats-every@|Print progress statistics at the given interval.
--log-errors|Compatibility option; error logging is already enabled.
--deprecated-xml-osclass|Use the older XML representation of OS classes.
# Program and compatibility
-h --help|Display Nmap’s usage summary.
-V --version|Print the installed version.
--datadir@|Look for Nmap data files in this directory.
--privileged|Tell Nmap to assume raw-packet privileges; this does not grant permissions.
--unprivileged|Tell Nmap to avoid features that require raw-packet privileges.
--nsock-engine@|Choose an available network I/O engine.
--release-memory|Compatibility option; current builds already release memory.
--nogcc|Internal compatibility switch; not a normal scan setting.
--thc|Novelty option; not a scan technique.
-I|Retired ident scan option; ignored with a warning.
-q|Accepted but has no effect in this release (no handler in nmap.cc).
-oH@|Unsupported: direct HTML output is rejected; use XML and a stylesheet instead.
-O1|Unsupported: first-generation OS detection was removed.
